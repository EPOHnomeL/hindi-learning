# pedagogy — scoping tickets

From the 2026-07-15 grilling: two tickets, deliberately separate. The teach skill already
frames **Knowledge → Skills → Wisdom** and delegates wisdom to external communities; these
tickets push the model further — full learning-pyramid coverage and first-class experiential
learning.

| # | Ticket | What it scopes |
|---|--------|----------------|
| 01 | [Learning-pyramid phases](issues/01-scope-learning-pyramid-phases.md) | A phase for every pyramid step; **structural vs policy is the scoping question** |
| 02 | [Experiential learning](issues/02-scope-experiential-learning.md) | Knowledge→wisdom: real-world assignments, teach-back, reporting back |

Seams: course-modules/01 (structural container), knowledge-grilling/01 (diagnostic),
ai-chat/03 (the discussion step), ai-chat/04 (apply-coaching — conversation, not structure),
rich-media (the audio-visual step).
